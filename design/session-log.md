# Session log

The parking lot for a local session: notes, ideas and open questions the owner and the agent set aside while working, so they don't derail the task at hand. Anything goes here, in Chinese or English, without the polish a living doc needs.

Before the session's final PR opens, the agent wraps it up: a short report to the owner of each note and where it should go — the tracker, a spike, a README, AGENTS.md, or nowhere. Once the owner agrees, each note moves there or is dropped, and this file is left with only this header.
