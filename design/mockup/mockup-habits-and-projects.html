Habits & Projects：一页两个 tab，lifecycle 替代 archive

现在的 Projects 页长成 Habits & Projects：两个醒目的 tab 共用一套 lifecycle（Active 常显，Paused / Completed 折叠），页头说清上限。Habit 卡重新设计（标题 · description · cadence · 进度信号），project 侧以现在的 ProjectCard / ProjectDetail 为基础。已定照画（屏 1–3、5）；要 owner 选的只有一件：habit 卡的进度信号（屏 4，三种并排）。全程没有 size / points / % / streak，没有红色。Fixture：W45 · Mon Nov 2 – Sun Nov 8 2026，今天 Thu Nov 5。

Before · 现在：Projects 页 + plan form 里的 habit template 行

现在的 Projects 页（从 ProjectsPage / ProjectList / ProjectCard / ArchivedSection / ProjectDetail / ProjectStep 画出来）：左列表每张卡有 done/total 文字 + progress bar + 「Next: …」+ 「N this week」pill；底部一个 Archived accordion，archive 是唯一的「结束」。右侧详情的 header 再画一次 progress bar 和「3 of 9 steps」；步骤行里 this week 的 tinted + 「This week · todo」pill，done 的 muted + ✓ 日期，没排的带 size chip 和「+ This week」。Habit 在这一页没有位置。

After · Habits & Projects · Habits tab（桌面）· 点 tab、折叠区、卡片、… 都能试

已定项的画法。页头是页名 + 一行文字 3 of 3 habits · 2 of 4 projects（不画三段小条——会和 project 的 path 撞形；满了也不变色）。两个 tab 是全宽 segmented control：选中段填充底色 + 加粗 + kind 色，三个指示（NN/g：两个 tab 时细线一条不够）；计数不放 tab 上，页头已经说了（Principle 1）。Lifecycle 不做 filter chips（segmented control 下再叠一排控件会读成两层 tab）：Active 常显，Paused n 和 Completed n 是两个折叠区，沿用现在 Archived 的 accordion（chevron + label + muted 数字 + hairline）；两个 tab 用同一套。上限满时变化落在动作上：「+ New habit」变成 muted 的 3 of 3 · Pause one to add，点它展开 Paused 区——Streaks「archived 住在 Add 屏」的变体，也是 spike 痛点 2 的出口。

Habit 卡和 board 卡同一张脸（kind 边、Habit 字样、标题、description）；右上角 cadence 是定义（Daily / 4× / week），不是进度；进度信号这里先用推荐的 (c)（屏 4 并排三种）；右上角可见的 … 收 Edit · Pause · Complete——长按作快捷路径，不是唯一路径（HIG context menu 要有可见替身）。右侧详情是最简版本：cadence 编辑（Daily ↔ Times per week + 数字）、本周每个 instance 一行、12 周 history（同一把尺：满高 = 达标，没有数字）、Pause / Complete 两个 outline 按钮。

After · Projects tab（桌面）· 以现在的 ProjectCard / ProjectDetail 为基础

卡片去掉 done/total 文字和 progress bar，换成和 board 卡同一个零件 path() 拉宽（9 段 / 4 段，done 实心、这周排的那步带环）——一个元素一个意思（Principle 1）；保留「Next: …」和「2 this week」pill（它们说的是别的事：下一步是什么、这周排了几步）。详情 header 右侧的 status 是一步可改的下拉（Active ▾ → Pause / Complete），不再有 Archive 按钮；progress 文字换成同一条 path。「All steps done」banner 的两个动作变成 Complete 和 Add next steps（下方单独画了它的样子）。Paused / Completed 折叠区和 Habits tab 同形。

细节 · 「All steps done」banner · 和「Complete · N steps left」的菜单

左：一个 project 的 step 全部做完时，详情顶部的 banner（旗子 + 两个动作），Complete 不弹框，直接进 Completed 区 + toast Undo。右：还有 step 没做完就想结束的 project，status 菜单里把后果写进标签 Complete · 2 steps left，剩下的 step 跟着收起（OmniFocus 的做法）——不另设 Dropped / Canceled 第四态，要 owner 拍板（屏 6 末尾）。

Before / After · 手机 · 列表 → 详情两层

Before：现在的 Projects 页手机版——一行一个 project（标题 + 3/9 · Next: … + chevron）、全宽「New project」、Archived accordion。After：页头、segmented control、Active 列表、「+ New habit」/「+ New project」在各自 tab 里、两个折叠区，和桌面一个结构；卡片同一张脸（Principle 2），点卡进详情，详情顶部「‹ All habits」回列表（和现在 Projects 的「‹ All projects」一样）。手机上 … 打开底部 action sheet（屏 5）。Dock 上这一页仍占 Projects 的位置，标签改什么（Habits? Focus?）留给 owner。

并排画 · habit 卡的进度信号 · 三种都画，每种三张 active 卡 + Paused / Completed 各一行 + 手机

这一页是 lifecycle 页，不是打卡页：用户来这里决定 continue / pause / complete。信号要回答的是「该不该动它」，而 board 卡上的 dots 回答的是「这周做到哪」。三种都不显示 size、points、完成率、streak。Fixture：Workout Daily 6/7 · 5/7 · 7/7 · 4/7，本周 Mon ✓ Tue ✓ Wed 空心 Thu 带环；LeetCode 4× / week 3 · 2 · 4 · 3，本周 3 个 ✓；Read 3× / week 3 · 3 · 2 · 3，本周 1 个 ✓。

排序 (c) > (b) > (a)，推荐 (c)。(c) 的关键改法：柱子只画之前的 4 个完整周、放在 dots 左边、底边对齐、同一色；dots 只负责本周——否则本周会画两遍（Principle 1）。柱子窄而方、dots 圆，形状区分「过去」和「现在」，整体读成一条 过去 → 现在 的时间线。上限 3 张卡，有空间（Principle 5）；Paused / Completed 行把 dots 换成「Paused since …」文字、柱子保留到停下那周，三种状态下卡上都有东西可看。

已定 · Pause / Complete / Resume 的交互 · 不弹确认，两层反馈 + 永久的 Resume · 可试：点 … → Pause

交互。卡片右上角 … 打开菜单：Edit · Pause · Complete，Complete 带一句副文案「Something you do without having to think about it」（借 SRBAI 的措辞，提醒 Complete = 内化了，不是放弃）。不弹确认框（HIG Alerts：常见、可撤销的动作不用 alert；NN/g 的 cry-wolf）。反馈两层：卡片当场从 Active 滑进对应折叠区（240 ms，structural）、区头的数字 +1；底部 toast「Paused Read · Undo」停留 5 s（Gmail 的时长；Material 默认对「卡片已消失」太短），和 Priorities 页现有的 undo toast 同一样式。Paused 区里的 Resume 是永久的 undo，一步回到 Active、历史保留；Completed 区保留「Back to active」（Renfree 2016：打卡可能已是拐杖，过早宣布完成要能回来）。Project 同一套：status 下拉 / 卡片菜单 → 同一个动画、同一个 toast。

手机 · … 是底部 action sheet · toast 在 dock 之上

手机上长按卡片也打开同一张 sheet（快捷路径）；swipe 不做——撞 board 的拖拽，也不可发现。Paused 行的 Resume、Completed 行的 Back to active 都是可见按钮，不进菜单：Habitify 把「停」埋在编辑表单底部、「恢复」放在另一个地方，用户因此要求「一个还看得见、灰掉的 pause」——这里直接回应它。
