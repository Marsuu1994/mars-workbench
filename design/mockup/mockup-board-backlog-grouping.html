How other products group repeats and sequences

Collapsed stack

iOS notification stacks · Android group summary
One full card with one or two edges peeking below; tap to fan out, "Show less" to fold. Android keeps every child a full notification (docs). iOS mostly implies the count by the layers.
→ A. Risk seen there: users tapping the stack expect it to open, not expand (Apple Community) — keep expand and ↑ Todo as separate targets.

Thread row + count

Gmail conversations
One row, a "(3)" after the sender; open to see all. The densest form, but it never says which one is next.
→ the ×N / +N chip in A, C and D.

Next-action gating

OmniFocus sequential projects · Sunsama recurring tasks
A sequential project shows only its first available action; the rest wait behind it (Omni manual). Sunsama shows only the next instance of a recurring task, never a pile (help).
→ C. Fits project steps exactly; the step path already says where it sits, so no number is needed.

Grouped section / accordion

Sunsama backlog folders · Todoist / Things headings
A header with a count, every item still its own draggable card underneath (Sunsama backlog).
Clear drag semantics, but expanded it is the long list again — the problem moves, it doesn't go.

Quota counter

Anki deck list · Streaks
Anki's deck rows show New / Learning / Review counts that drop by one per card (docs). Identical repeats don't need a card each.
→ D's habit row.

Parent with fraction

Todoist subtasks · Linear sub-issues
Collapsible parent with "2/5"; Linear toggles sub-issues on and off in Display options (docs). Jira's board can't fold sub-tasks under their parent — a standing feature request (JRACLOUD-86472).
A possible later add-on: a Grouped / All toggle, grouping as a view only.

Common thread: counts say how many are left, not which one this is — B's number goes against that, and repeats what the step path already shows. The patterns that let you take one directly (gating, quota) expose exactly one actionable thing; the ones that must expand first (stacks on iOS) are where mis-taps happen on phones.
