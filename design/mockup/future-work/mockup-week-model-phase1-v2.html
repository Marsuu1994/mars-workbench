Phase 1 three kinds of work · what ships · what waits

Ships in phase 1

  • Projects — Plan › Projects: a goal and an ordered list of steps; steps go onto the week one by one and never expire. New Project / Add Step modals follow the TaskModal pattern — see mockup-projects-v2.html
  • Kind-first cards on the board, the backlog and the mobile rows — habit, project step or one-off in the first line, the kind's own progress in the last
  • Risk off — no risk badge, no risk border, no 15:00 / 20:00 thresholds
  • Doing column removed — the board is Todo · Done; work in progress stays in Todo, and tasks already in Doing move to Todo
  • Plan form shows the plan's project steps next to one-offs — select / deselect only
  • MCP — Claude reads projects, creates them, writes steps and puts steps on the week

Stays as it is

  • The name Todo, the backlog and drag and drop
  • Templates, type × frequency per plan, Plan Mode, the plan form, the AI chat
  • Daily rollover (now a neutral ↩ date on the habit card)
  • The priority matrix and Track This Week (minus its In Progress target)
  • The backlog drawer / sheet, sizes and points

Waits

  • Phase 2 — habits own their cadence (Daily or N× / week, Plan Mode dropped), Habits page, three-step Plan week, AI chat removed, Done as a day-grouped log with ✓ on cards, quiet habit expiry
  • Tracker — per-kind risk rules, one-off due dates, daily rhythm rituals, backlog stacking, habit-level days, own entries for habits and projects
Before today — template instances, risk on every card

The project-like work is a weekly template, so the board says "Biomedical course #3" and "Protein 3D visualizer #1", not which lecture or which step. Four unrelated meanings share one coloured border and pill.

After phase 1 — Todo · Done, same drag and drop, new cards

The Doing column is gone — Todo and Done remain, and the backlog and drag and drop are unchanged. Each card now opens with what it is: a habit (green, with its plan line — Daily / 3× / week), a project step (purple, with the project and step n of N) or a one-off (blue, with its quadrant). The last line is that kind's progress: week dots for a habit, the path for a step. Nothing turns amber or red. Tuesday's rolled-over Workout says ↩ Tue, Oct 6 where the cadence would be. The Mol* step that was in progress sits in Todo like any task.

Rules

1One channel per meaning

The kind colour never changes on a card, and no other meaning uses it. Warning and error stay free for risk when it comes back; accent stays the drag-target colour; primary stays the CTA colour (it is red in P5).

2Risk is off

Phase 1 removes the risk badge, the risk border and the clock thresholds (15:00 / 20:00) together with the card's old layout. Per-kind risk — habit pace, a step carried twice, a one-off's due date — is in the tracker and comes back as a colour on the signal line, never on the stripe.

3Rollover, until phase 2

Daily rollover still exists in phase 1. A rolled-over habit shows ↩ date in the context slot in a neutral colour, instead of a warning-coloured tag. Phase 2 removes rollover entirely (missed days expire quietly).

Before create plan — carry-over is one-offs only
After unfinished steps carry over like one-offs · click to toggle

The plan form is otherwise untouched in phase 1 (its redesign is phase 2). It only renders the plan's selected project steps — last week's unfinished ones when creating, this week's when editing — and, like one-offs, you can only select or deselect them; deselecting sends a step back to its project at the same place. It only loads steps that already exist — nothing here adds a project or a step; that lives on the Projects page. Phase 2 revisits this.
